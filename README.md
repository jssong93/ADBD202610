## 암장 목록

현재 후보 25곳. 사용자가 요청한 서울숲클라이밍 뚝섬, 클라이밍파크 한티, 더클라임 서울대점을 삭제했습니다. 더클라임 성수는 이전 목록에도 없었으며 계속 제외 상태입니다. 클라이밍파크 성수는 별개 암장이므로 유지했습니다.

앞서 요청한 더클라임 홍대B·신사 제외, 투이얼즈 염창으로 이름 변경, 캐치스톤 부천 유지도 반영되어 있습니다.

## 이미지 저장 및 공유 수정

기존 blob: 임시 주소 다운로드를 없애고 실제 1080 × 1350 JPG 파일로 저장하도록 변경했습니다. 확장자 .jpg, 파일 MIME image/jpeg, 실제 JPEG 바이트를 일치시켰으며 파일명은 영문을 사용합니다. 각 JPG는 약 180KB입니다. 날짜는 표시하지 않습니다.

### 안드로이드 카카오톡 내장 브라우저

1. 암장을 뽑습니다.
2. 이미지 저장 또는 카카오톡으로 이미지 공유 버튼을 누릅니다.
3. 미리보기에서 JPG 다운로드를 누르거나 이미지를 길게 눌러 저장합니다.
4. 저장한 사진을 카카오톡 대화방에 첨부합니다.

다운로드가 계속 막히면 미리보기의 '크롬에서 같은 결과 열기'를 누르세요. 당첨 암장을 URL에 담아 크롬에서도 같은 결과를 복원합니다. 크롬 실행이 기기에서 막히는 경우 카카오톡 메뉴의 다른 브라우저로 열기를 사용하세요.

카카오톡 내장 브라우저에서는 파일 공유를 강제로 호출하지 않습니다. 카카오톡으로 자동 전송하는 버튼이 아니며, 브라우저에서 허용하는 저장/공유 방식을 사용합니다.

### 크롬 등 일반 브라우저

파일 공유를 지원하면 시스템 공유창에서 카카오톡과 대화방을 선택합니다. 미지원 또는 오류 발생 시 이미지 저장 미리보기로 연결됩니다. 취소는 취소 상태로 안내합니다.

파일 공유는 HTTPS 페이지에서 사용하세요. 내장 브라우저 제한은 사이트 코드만으로 해제할 수 없습니다.

## 검증 및 한계

Edge에서 실제 로컬 HTTP 서버를 사용해 JPG 다운로드 파일을 확인했습니다. 25개 JPG 전체가 1080 × 1350 이미지로 디코딩됨, 후보 목록, 당첨 포인터 각도, 미리보기, 같은 결과 URL 복원, 오래된 이미지 요청 차단, 모바일 가로 넘침 없음, 스크립트 오류 없음 확인.

공유 성공/취소/실패 및 안드로이드 카카오톡 경로는 브라우저 API와 사용자 에이전트를 모의해 검사했습니다. 실제 안드로이드 카카오톡 앱에서 다운로드·크롬 실행·메시지 전송까지 확인한 것은 아닙니다. 업데이트 후 해당 휴대폰에서 확인이 필요합니다.
