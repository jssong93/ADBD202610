# Red Panda Climb Club — 클라이밍 룰렛

## GitHub Pages에 적용

ZIP을 풀고 폴더 안의 다음 파일을 저장소 루트에 업로드하세요.

- index.html
- assets/red-panda.png

기존 index.html과 이미지를 교체하면 됩니다. 별도 설치나 API 키 없이 동작합니다. GitHub Settings > Pages에서 배포하고 HTTPS 주소로 접속하세요. 파일을 더블클릭한 file:// 환경은 브라우저 보안 제한으로 PNG 생성이 실패할 수 있습니다.

## 변경 사항

- 차콜·올리브·오렌지 디자인, 모바일 대응
- 근육질 클라이머 렛서팬더 이미지 교체
- 더플라스틱 염창 → 투이얼즈 염창 (사용자 요청 반영)
- 더클라임 홍대B·신사점 폐점 반영: 후보 제외 (사용자 확인)
- 캐치스톤 부천 후보 복원 (사용자 정정 반영), 총 28곳
- 1080 × 1350 결과 PNG 생성, 이미지 공유 및 저장 버튼
- 저장소 접근이 차단된 브라우저에서도 룰렛 동작

## 후보 정리 / 2026-10-13 사용자 확인 반영

더클라임 홍대B와 신사는 폐점한 것으로 사용자 확인을 받아 후보에서 제외했습니다. 원본의 '더클라임 홍대점'은 홍대B 항목으로 처리했습니다.

캐치스톤 부천은 사용자 정정에 따라 후보에 복원했습니다. 이전 사업자 폐업 자료만으로 매장 폐점을 판단한 안내는 삭제했습니다.

현재 후보는 28곳입니다. 그 외 지점은 유지했으며, 방문 전 최신 운영시간을 확인해 주세요.

## 카카오톡 이미지 공유 방식

룰렛 당첨 이후 결과 PNG를 미리 생성합니다. 버튼을 누르면 파일 공유를 지원하는 휴대폰/브라우저의 시스템 공유창이 열립니다. 사용자가 카카오톡과 대화방을 선택합니다. 카카오톡 설치 여부와 공유 대상 노출은 기기/브라우저에 따라 다릅니다.

파일 공유를 지원하지 않는 PC나 브라우저에서는 PNG를 다운로드합니다. 저장한 이미지를 카카오톡 대화방에 첨부하세요. 별도의 '이미지 저장' 버튼도 있습니다. 자동 전송 또는 카카오톡 전용 SDK 직접 호출 방식은 아닙니다.

## 검증

Edge 브라우저에서 원본 파일을 HTTP 응답으로 공급하여 검사했습니다. 데스크톱 및 390px 모바일 화면, 룰렛 결과와 포인터 각도, PNG 다운로드, 자바스크립트 오류 없음, 모바일 가로 넘침 없음 확인. 실제 휴대폰의 카카오톡 전송은 별도 실기기 확인이 필요합니다.
